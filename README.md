# CIPA Arouca Fechaduras

Aplicativo digital para gestão da CIPA na Arouca Fechaduras.

## Funcionalidades
- **Denúncias, Sugestões e Reclamações**: Envio seguro e anônimo.
- **Acompanhamento**: Consulta via código único de 8 caracteres.
- **Painel Administrativo**: Gestão de status, respostas e exclusão de registros.
- **Placar de Segurança**: Controle de dias sem acidentes atualizável via painel.
- **Persistência**: Integração total com Supabase (Cloud Database).

## Tecnologias
- HTML5 / CSS3 / JavaScript Vanilla
- [Supabase](https://supabase.com/) (Banco de Dados)
- [Lucide Icons](https://lucide.dev/) (Ícones)

## Configuração
O projeto está configurado para conectar ao Supabase via CDN. Os dados são salvos nas tabelas `denuncias`, `sugestoes`, `reclamacoes` e `settings`.
